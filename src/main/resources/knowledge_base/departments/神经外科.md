# 神经外科

## 科室简介

四川大学华西医院神经外科创建于上世纪50年代，是我国最早的神经外科专科病房之一，也是卫生部（现国家卫健委）全国首批三大神经外科临床医生培训基地之一。国务院首批博士学位、硕士学位授权点。国家卫生计生委（现国家卫健委）首批国家临床重点专科，世界神经外科联合会在大陆地区两个继续教育中心之一。目前神经外科包括华西坝本部、上锦院区、天府院区三个临床院区和华西医院神经疾病研究所，开放床位440张，其中NICU床位70张。华西医院神经外科年门诊量超过十万余人次，年开颅手术量接近14000台，血管内介入手术2600余台，立体定向放射神经外科手术2000余台，是西部地区最大的神经外科基地。
