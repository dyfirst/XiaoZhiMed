# 呼吸与危重症医学科

## 科室简介

四川大学华西医院呼吸与危重症医学科是中国西部地区呼吸病学的发源地之一，是我国首批硕士学位授予点，第三批博士学位授予点和博士后流动站，为教育部首批重点学科及卫生部临床重点专科，全国首批十家PCCM规范化专科建设示范单位，同时也是国内呼吸治疗专业的发源地，多年来在医疗、教学、科研、管理等方面硕果累累，在全球久享盛誉。我科本院设有呼吸病房、呼吸综合病房、结核病房、MICU病房、锦江呼吸病房及温江肺癌中心病房，同时上锦院区、天府院区及锦城院区等分院均设有呼吸病房，合计床位300余张，为全国床位数最多的呼吸与危重症医学科之一。同时设有肺功能室、呼吸内镜中心、睡眠医学中心等。科室现有工作人员300余人，其中正高24人，副高27人，长江学者、国家杰青及国家优青、青年拔尖人才7位，博士生导师18人，硕士生导师11人。90%的医生拥有博士或硕士学位，护士均具有大学本科或大专学历。绝大多数医师均有出国学习或培训、参加国际学术会议经历。我科与美国、德国、英国、加拿大、澳大利亚等国家的多家大学医院呼吸与危重症医学科建立了密切的合作关系。保持了华西百年优良传统的高素质和高学历医护队伍，使我科的医疗、护理质量在国内处于领先水平。与国外同行的广泛交流，使我们不断引进欧美国家的高新医疗技术解决临床疑难问题。目前我科每年平均诊治门诊患者12万余人次，住院患者万余人次。主要诊断和治疗内科和呼吸系统的常见病、多发病，如肺炎、慢阻肺、肺心病、哮喘、呼吸衰竭、急性呼吸窘迫综合征、肺癌、气胸、胸腔积液、肺血栓栓塞症等；对疑难病如弥漫性间质性肺疾病、肺囊性纤维化等的诊治水平居中国西部前茅。自建科以来开创多项引领国内外的临床前沿技术，2007年与胸外科联合行中国西部第一例肺移植，近年恢复每年开展10-20例。建立了华西肺癌精准早诊体系并推广全国，完成了亚洲首例电子气管镜下热蒸汽肺消融术，世界首例新型导管肺部靶向去神经射频消融术，填补了国际国内相关领域的空白。率先在西南地区开展了支气管热成型术，为重症哮喘患者提供了新的治疗方法。此外，医院还设有国家呼吸和共病全国重点实验室、呼吸健康研究院、国家生物治疗重点实验室呼吸病学研究室等国家省部级研究平台，产出了一系列高质量创新研究成果。
