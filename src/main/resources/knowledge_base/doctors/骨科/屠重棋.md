# 屠重棋

- 科室：骨科
- 职称：主任医师

## 个人简介

骨科副主任，骨肿瘤中心主任，博导，一级专家。四川省学术技术带头人，四川省“劳模”，连续3年获“中国名医骨肿瘤TOP10。35年骨肿瘤工作，年手术500台，保肢术4000例。现任国家级学会副主委4个、常委2个、组长和副组长3个。获国家级项目3项、省部级10项，发表论文180篇，专利13项。专业擅长
诊治范围：1各类骨与软组织肿瘤及骨转移瘤；②2各类骨缺损；3各种畸形及疑难病。 专业擅长：1恶性骨肿瘤和骨转移瘤的综合保肢治疗；2 3D打印假体置换保肢术；3骶骨及骨盆肿瘤切除重建保肢术；4重度四肢畸形矫正术。
