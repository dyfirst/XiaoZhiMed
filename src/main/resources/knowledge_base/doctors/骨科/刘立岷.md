# 刘立岷

- 科室：骨科
- 职称：主任医师

## 个人简介

博士生导师，一级专家。1993年留校工作至今，多次国内外顶级矫形中心（美国TSRH医院、法国里昂CMCR中心等）研修脊柱畸形的诊断治。年门诊量3000人，年手术量400台。主持国家级、省部级课题课题5项。发表SCI论文60余篇，曾获教育部科学技术进步奖一等奖、四川省科技进步三等奖。

## 专业擅长

诊治范围：各种脊柱相关疾病，包括脊柱畸形、脊柱退变、脊柱肿瘤、脊柱结核、强直性脊柱炎等。 擅长：1.脊柱侧凸及其他脊柱畸形的手术治疗；2.退变性颈、腰疾患治疗（如颈、腰椎间盘突出等）；3. 脊柱结核、肿瘤等骨病的外科治疗；4.脊柱内镜微创手术。
