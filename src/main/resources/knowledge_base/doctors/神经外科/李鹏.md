# 李鹏

- 科室：神经外科
- 职称：主任医师

## 个人简介

李鹏，医学博士，主任医师，研究生导师，功能神经外科医疗组长，四川省卫健委学术技术带头人后备人才，荷兰阿姆斯特丹大学医学中心（AMC）和东京女子医科大学（TWMU）访问学者。担任：中国神经调控青年医师Talent X委员会主席，中国医师协会神经调控专业委员会青年委员，中国人体健康科技促进会神经调控及神经修复专业委员会委员，世界华人神经外科医师协会放射神经外科专委会委员，中国抗癌协会颅内肿瘤微创综合治疗分会常务委员，四川省医师协会神经外科专委会委员等社会职务。发表国内外论文三十余篇，论著多部，承担各类课题多项。获得全国神经外科青年医师手术及程控大赛双料三甲。

## 专业擅长

擅长机器人和立体定向手术，完成DBS/SCS、伽玛刀及脑活检手术近万例。脑起搏器治疗（DBS）：帕金森病、梅杰氏病、特发性震颤、肌张力障碍、微小意识状态等。伽玛刀治疗各种颅内肿瘤和血管病。脊髓电刺激治疗（SCS）：腰背术后疼痛、缺血性疼痛（如糖尿病足、雷诺氏病等）、区域性疼痛综合症、带状疱疹性疼痛、脊髓和神经损伤相关病理性疼痛以及植物人促醒等。
