# 马潞

- 科室：神经外科
- 职称：研究员

## 个人简介

教授/研究员，博士生导师，四川省卫健委第十四批学术技术带头人。四川大学华西医院神经外科脑血管病中心医疗组长。2011年-2012年在纽约大学Langone医学中心神经外科学习脑血管病及颅底外科。任世界神经外科协会（WFNS）国际教育华西培训基地秘书，中国医师协会神经外科分会外事委员会委员、国家卫健委脑防办专家委员会委员、海协会神经外科分会脑出血学组秘书及脑缺血委员等职。作为负责人主持国家科技部重点研发计划、国家自然科学基金及四川省科技厅重点研发计划，目前在研总经费近千万。作为CO-PI负责华西-乔治中心国际多中心临床研究“INTERACT 3”，作为第一执笔撰写自发性脑出血诊断与治疗中国多学科专家共识（2015版）、负责中国多学科脑出血诊断与治疗指南（2020版）。以第一及通讯作者在Neurology、JNS、World Neurosurgery等专业杂志发表论文40余篇，获发明专利2项。

## 专业擅长

脑血管病包括脑出血、颅内动脉瘤、脑血管畸形、烟雾病及颈动脉狭窄的手术治疗；颅脑外伤及颅脑肿瘤的手术治疗。
