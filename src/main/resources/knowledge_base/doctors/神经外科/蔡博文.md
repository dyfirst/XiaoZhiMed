# 蔡博文

- 科室：神经外科
- 职称：副主任医师

## 个人简介

蔡博文，主任医师，医学博士，华西医院垂体瘤及相关疾病诊疗中心副主任，四川省医师协会颅底神经外科专业委员会副主任委员，中国垂体瘤协作组核心成员，中国医促会神经外科专委会委员，中国抗癌协会神经肿瘤专委会垂体瘤学组委员，中国罕见病联盟下丘脑垂体学组委员，中国医师协会神经内镜专委会第三、四届委员会委员，海峡两岸医药卫生交流协会颅底神经外科专委会委员，中国医药教育协会神经肿瘤分会委员，原卫生部神经科内镜专家考评委员会常务理事。毕业于北京医科大学，多年来在颅底疾病尤其是垂体瘤的规范化、个体化诊疗及颅咽管瘤、颅底脑膜瘤的外科治疗等方面进行了深入的探索和研究。参与了近年来中国垂体瘤及中国神经内镜相关多项指南和共识的编写、制定工作。获得中华医学科技一等奖、三等奖各一项；华夏科技奖、教育部、省市级科技成果二等奖及三等奖多项，发表论著130余篇，参编专著4部。

## 专业擅长

颅内各部位神经肿瘤包括脑膜瘤、垂体瘤、胶质瘤、颅咽管瘤、脑转移瘤的微创显微外科诊疗，2012年来作为召集人组织了华西垂体瘤及相关疾病多学科诊疗工作。
