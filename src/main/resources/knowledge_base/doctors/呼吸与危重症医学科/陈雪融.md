# 陈雪融

- 科室：呼吸与危重症医学科
- 职称：主任医师

## 个人简介

陈雪融，女，医学博士，加拿大麦克马斯特大学感染与免疫博士后，四川大学华西医院呼吸科结核亚专业教授，一级专家，硕士导师，四川省卫健委学术带头人，中华医学会结核病学分会委员、中华医学会结核分会互联网专委会主任委员，中国防痨协会临床专委会常委兼副秘书长、中国防痨协会非结核分枝杆菌病专委会副主委，四川省医学会结核病学专委会主任委员。发表论文50余篇，其中SCI10余篇（最高IF25），承担国家自然科学基金等7项课题，主编专著2部，参编专著10余部。

## 专业擅长

从事结核病临床诊疗与基础研究二十余年，擅长疑难结核、耐药结核、重症结核、非结核分枝杆菌病的诊治.
