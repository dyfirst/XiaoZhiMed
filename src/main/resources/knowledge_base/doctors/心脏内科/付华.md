# 付华

- 科室：心脏内科
- 职称：主任医师

## 个人简介

四川大学华西医院心血管内科主任医师、教授。现任四川大学华西医院心内科心律失常专业组组长；中华医学会心电生理和起搏分会委员；中国生物医学工程学会心律分会委员；中华医学会心血管病学分会心律学组委员；中华医学会心电生理和起搏分会心房颤动工作委员会委员；中华医学会心电生理和起搏分会基础研究学组委员；中华医学会心电生理和起搏分会第六届委员会左心耳封堵工作委员会副主任委员；中国生物医学工程学会心律分会室性心律失常与猝死工作委员会委员；四川省医学会心电生理和起搏专委会副主任委员；四川省医师协会心血管内科医师分会副会长。

## 专业擅长

以早搏及心动过速为表现的各种快速型心律失常，尤其是心房纤颤/心房颤动（简称房颤）的导管消融治疗，房颤“一站式手术”治疗；在各种室性心律失常（早搏及室性心动过速）、房性心动过速、阵发性室上性心动过速等复杂型快速心律失常射频消融治疗均有极深的造诣。
