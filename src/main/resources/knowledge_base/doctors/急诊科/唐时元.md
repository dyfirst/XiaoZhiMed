# 唐时元

- 科室：急诊科
- 职称：副主任医师

## 个人简介

四川大学硕士，副主任医师，2016年赴香港中毒咨询中心学习临床毒理学。2012年美国心肺复苏与心血管急救BLS/ACLS导师资格认证，2016年获美国创伤学会ATLS课程资质认证，2018年获美国灾难生命支持课程（NDLS）导师资格认证。 先后参与国家自然科学基金科研项目3项、参与国家重点建设项目2项、省部级课题主研2项，负责四川大学教改项目1项，以第一作者或通讯作者发表文章7篇，其他排名发表文章十余篇；参与撰写书稿4本5万余字。担任四川大学灾难医学中心秘书，四川省医师协会急诊医师分会秘书，四川省医学会灾难医学分会青年委员会副主委。

## 专业擅长

从事急诊急救临床一线工作14年，擅长急诊危重症、急性中毒、急性多发伤的临床救治；多次参加包括芦山地震、尼泊尔地震等灾难现场紧急医学救援工作。
