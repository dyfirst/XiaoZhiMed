# 赖世超

- 科室：急诊科
- 职称：主治医师

## 个人简介

四川大学华西医院急诊科 主治医师。发表中文8篇，SCI论文3篇，专利3项，参编人民卫生出版社出版《县医院继续医学教育培训系列教材（内科分册）》《全科医生临床操作技能训练》《基层医务人员继续医学教育培训手册（乡镇社区医师手册）》《基层医务人员继续医学教育培训手册（乡村医生版本）》，负责或参研国自然、四川省、成都市课题7项。华西急诊国际学术论坛会议秘书、四川省卫生应急队队员、四川省医院协会急救中心（站）管理分会急救培训管理委员。AHA BLS/ACLS Provider培训师资，急诊住院医师导师。参与急性百草枯中毒早期诊治及预后评估，成都市科技进步二等奖申报。曾获“全国三级医院对口帮扶贫困县医院工程”中为尼玛县医疗卫生事业和人才培养作出突出贡献奖、成都市百万职工技能大赛医疗急救比赛荣获“优秀选手”、四川大学华西医院“华西青年榜样”、“优秀团干”、新冠肺炎疫情防控工作院级“先进个人”

## 专业擅长

一直从事急危重症、心肺复苏、中毒、创伤患者的救治工作13年。对多发伤诊治流程、心肺复苏质量监测、脓毒性休克的血流动力学管理、危重患者床旁超声的应用有一定造诣。
