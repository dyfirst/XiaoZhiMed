# 陈涛

- 科室：内分泌代谢科
- 职称：主任医师

## 个人简介

临床医学博士，副教授，硕士研究生导师。2008年至2009年美国匹兹堡大学医学院做博士联合培养，进行了肥胖和糖尿病发病机制的研究。2013年在英国谢菲尔德大学参加糖尿病周围神经病变培训班。自工作以来，一直从事内分泌及代谢性疾病的诊治、科研及教学工作。负责并参与国家自然科学基金、四川省科技厅等课题多项。发表SCI论文及中文核心期刊文章40余篇。现为中华医学会内分泌分会免疫内分泌学组委员，中国医疗保健国际交流促进会中老年医疗保健分会委员；四川省医疗卫生与健康促进会内分泌代谢专委会副主任委员；四川省国际医学交流促进会糖尿病及代谢性疾病专业委员会常委委员；四川省医学心理学专委会委员。四川大学华西医院肾上腺疾病诊治中心秘书。

## 专业擅长

肾上腺疾病/内分泌高血压；糖尿病及其并发症（糖尿病足患者请到糖尿病足病专业门诊就诊）；肥胖及高脂血症；甲状腺疾病；痛风及高尿酸血症等；内分泌代谢疑难疾病。
