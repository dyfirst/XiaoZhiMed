# 李建薇

- 科室：内分泌代谢科
- 职称：副主任医师

## 个人简介

医学博士，硕士生导师，四川省卫健委学术技术带头人。卫生部移植工程与移植免疫重点实验室博士后，美国佛罗里达大学医学院糖尿病研究中心访问学者。现为中华医学会内分泌分会垂体学组委员，中华医学会糖尿病分会1型糖尿病学组委员，四川省预防医学会内分泌代谢性疾病防控分会副主任委员，四川省中西医结合学会内分泌专委会常委，四川省医师学会内分泌分会委员，成都市医学会内分泌专委会委员。担任内分泌代谢科医疗组长，从事垂体相关疾病、糖尿病及肥胖等内分泌代谢疾病的临床及基础研究

## 专业擅长

1.垂体相关疾病（肢端肥大症、库欣病、TSH瘤、泌乳素瘤、垂体前叶机能减退和尿崩症等；2.代谢性疾病（糖尿病、肥胖症、脂代谢紊乱、痛风和高尿酸血症等）；3.内分泌代谢相关疑难病及罕见病。
