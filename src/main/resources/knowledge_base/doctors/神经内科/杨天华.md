# 杨天华

- 科室：神经内科
- 职称：主任医师

## 个人简介

四川大学华西医院副教授，医学博士，硕士研究生导师。任中华医学会高原医学分会委员，四川省康复医学会癫痫与临床电生理学组副组长，成都市医师协会神经内科专委会委员。毕业于四川大学获医学博士学位。曾获国家留学基金委资助于德国纽伦堡大学留学1年。诊治神经内科常见疾病，包括癫痫及发作性疾病、痴呆等常见病多发病。负责国家自然科学基金、博士后基金、四川大学青年教师基金及四川省科技厅重点研发项目各1项。主要从事癫痫的基础及临床研究，发表第一及通讯作者SCI收录论文15篇。参研获得2012年教育部科学技术进步一等奖（排名第8）、2018年海南省医学科技奖一等奖（排名第3）、2020年四川省科学技术进步奖一等奖各一项（排名第7）。

## 专业擅长

癫痫及发作性疾病、帕金森等神经内科常见病，常见急慢性高原相关神经系统疾病。
