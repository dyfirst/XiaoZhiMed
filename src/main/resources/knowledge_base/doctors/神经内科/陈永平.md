# 陈永平

- 科室：神经内科
- 职称：副主任医师

## 个人简介

男，神经病学博士，副教授，博士生导师。曾赴美国马萨诸塞大学神经病学访学2年。在帕金森病、肌萎缩侧索硬化、额颞叶痴呆、肌张力障碍等方面有深入研究。任中华预防医学会自由基预防医学专委会青年委员会副主委，中国老年保健协会神经变性疾病专委会常委，中国罕见病联盟神经罕见病专委会委员，四川省预防医学会神经变性疾病防治分会副主委，四川省医学会罕见病专委会委员。先后主持国家自然科学基金2项，省科技厅支撑项目、博士后面上项目等多项课题。已第一及通讯作者发表论文50余篇，授权国家发明专利1项。获四川省医学科技进步一等奖（第二完成人），华西青年科研榜样等称号。

## 专业擅长

帕金森病、运动神经元病、肌张力障碍、痴呆等神经遗传病及运动障碍疾病的诊治。
