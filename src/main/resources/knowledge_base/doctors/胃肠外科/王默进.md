# 王默进

- 科室：胃肠外科
- 职称：主任医师

## 个人简介

四川大学华西医院胃癌中心书记/副主任，副主任医师/副教授，硕士研究生导师，中共党员。瑞典Linkoping大学博士后，四川省医师协会外科分会委员兼秘书长、四川省医学会肠外肠内营养青委会副主任委员等学会任职。从事胃肠道疾病和临床营养治疗工作近20年。擅长胃肠疾病外科及综合治疗，尤其是胃癌、胃食管结合部癌、胃肠间质瘤腹腔镜微创手术治疗及临床营养规范治疗。对胃炎、胃溃疡、小肠、结肠常见疾病诊断治疗，胃肠肿瘤早期诊断，青年胃肠癌遗传信息及家系筛查有较高造诣。
