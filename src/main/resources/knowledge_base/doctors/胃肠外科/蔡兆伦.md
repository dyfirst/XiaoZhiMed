# 蔡兆伦

- 科室：胃肠外科
- 职称：主治医师

## 个人简介

四川大学华西临床医学院外科学博士、博士后。中国抗癌协会成员、Cochrane协作组成员。担任Systematic Reviews、BMC Cancer等国际医学期刊编委。长期从事胃肠疾病临床和科研工作，擅长胃癌与胃肠间质瘤的诊治和研究，特别是外科治疗与术后康复。以一作或通讯发表相关学术论文50余篇，含SCI论文30余篇，多项研究结果被中国临床肿瘤学会胃肠间质瘤诊疗指南与美国胃癌NCCN临床实践指南等国内外权威临床指南引用。参编专著1部。

## 专业擅长

常见胃肿瘤规范化诊疗包括胃肠间质瘤、胃癌、食管胃结合部癌，胃肠外科常见急诊和围手术期并发症的诊治，胃肠术后康复与随访复查。
