# 杨丽

- 科室：消化内科
- 职称：主任医师

## 个人简介

消化内科/内镜中心主任,教授/主任医师、博士生导师。1984年毕业于华西医科大学临床医学专业，留校工作至今。一直从事有关消化系统疾病的临床、教学和科研工作。承担了如国家自然科学基金等多项国家级及省部级科研课题；以第一作者或通讯作者发表SCI论文数十篇；教育部、国家卫健委全国高等学校医学专业研究生国家级规划教材《消化内科学》及国家卫健委“十三五”规划临床医学专业?官-系统整合教材《消化系统与疾病》副主编。中华医学会肝病学分会委员、中国医师协会消化分会委员、四川省医学会第七届消化专委会主任委员及四川省医师协会消化医师分会候任会长。四川省学术和技术带头人、四川省卫生健康领军人才。

## 专业擅长

擅长消化系统疑难重症尤其是各种肝病如肝硬化、自身免疫性肝病、遗传代谢性肝病等的诊治。
