# 王显丁

- 科室：泌尿外科
- 职称：副主任医师

## 个人简介

四川大学华西临床医学博士，美国哈佛大学医学院/麻省总医院移植中心博士后，华西医院泌尿外科副主任医师、医疗组长，硕士生导师。中国国际卫生应急医疗队队员，中国医促会器官移植学分会委员，海峡两岸医药卫生交流协会器官移植分会委员，四川省医学会器官移植专委会秘书、肾移植学组委员。在国内外高水平期刊发表论文40余篇，参编学术专著3部，主持或参与国家自然科学基金、四川省科技计划项目、成都市科技计划项目等科研项目，研究成果多次获邀参加美国器官移植年会、欧洲器官移植年会、中国器官移植年会等学术会议。

## 专业擅长

1.活体肾移植和死亡捐献肾移植的评估、登记、手术；2.小切口肾移植；3.腹腔镜活体供肾切取；4.ABO血型不相合肾移植；5.肾移植术后长期随访及并发症处理。
