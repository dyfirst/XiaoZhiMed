# 邓实

- 科室：泌尿外科
- 职称：主治医师

## 个人简介

泌尿外科学博士。毕业于四川大学华西临床医学院相继获得外科学专业硕士、博士学位。2015年进入四川大学华西临床医学院博士后流动站，完成博士后研究工作。目前任四川省男科学专业委员会青年委员会副主任委员。

## 专业擅长

擅长泌尿系疾病的微创治疗，肿瘤治疗领域包括：腹腔镜下肾上腺肿瘤、肾肿瘤、肾盂、输尿管癌、膀胱癌、前列腺癌、阴茎癌的外科手术及综合治疗；男科治疗疾病领域包括：前列腺疾病、前列腺增生症、精索静脉曲张等。结石治疗领域包括：输尿管结石，肾结石采取输尿管镜，输尿管软镜进行微创治疗。对泌尿系晚期肿瘤，尤其对手术难以切除的占位病变可采取射频消融的方式进行处理。
