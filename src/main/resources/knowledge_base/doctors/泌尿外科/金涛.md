# 金涛

- 科室：泌尿外科
- 职称：主任医师

## 个人简介

四川大学华西医院泌尿外科学博士，四川大学医院管理MBA研修班，主任医师，硕士研究生导师，四川大学华西天府医院副院长，第十四批四川省卫生健康委学术技术带头人后备人选。现任中国装备协会泌尿外科分会委员、四川省优生托育协会生育力保护分会会长、成都高新医学会泌尿外科专委会副主任委员、四川省肿瘤学会（SCS）基因与免疫细胞治疗专业委员会常委、四川省国际医学交流促进会泌尿外科专委会常委、成都市医师协会第一届泌尿外科专业委员会常委、四川省医院协会城市医院工作委员会理事、四川省医师协会泌尿外科医师分会秘书、四川省预防医学会生殖健康分会委员。负责省、市级课题6项及四川大学华西医院管理课题1项，获国家专利5项，发表论文30余篇，其中第一作者及通讯作者发表SCI论文17篇及统计源核心期刊论文6篇。

## 专业擅长

1、各类型男性尿失禁的系统化诊断和治疗（尤其手术治疗）； 2、泌尿系统修复重建手术（各型尿道狭窄）； 3、泌尿男生殖系统晚期肿瘤微创治疗（射频、微波、粒子）；
