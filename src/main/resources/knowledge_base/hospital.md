# 四川大学华西医院

## 医院简介

四川大学华西医院（West China Hospital, Sichuan University）始建于1892年，是中国西部疑难危急重症诊疗的国家级中心，是中国最早的西医院之一。医院秉承"厚德精业、求实创新"的院训，已发展成为学科门类齐全、师资力量雄厚、医疗技术精湛、科研实力强大的综合性研究型医院。

连续多年在中国医院排行榜中名列第二，是中国西部地区规模最大、综合实力最强的医疗机构。

## 基本数据

- 医疗区占地 577 余亩
- 业务用房 67.62 万平方米
- 编制床位 4900 张
